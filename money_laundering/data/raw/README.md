# Raw Data

Dados brutos, imutáveis - primeira cópia dos dados sem qualquer processamento.

## Conteúdo

- Datasets originais do Kaggle/fontes externas
- Arquivos de backup dos dados originais
- Dados exportados diretamente de sistemas

## Regras

- **NUNCA** modifique arquivos nesta pasta
- Use apenas para leitura
- Mantenha metadados sobre origem e data de coleta

## Arquivos Grandes

Arquivos grandes (> 10MB) são ignorados pelo Git.
Para compartilhar, use:
- Google Drive/OneDrive links
- DVC (Data Version Control)
- Compressed samples
